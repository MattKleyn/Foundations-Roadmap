# Depth Checklist
How deep is too deep and when have I barely scratched the surface? Do I have a solid conceptual and working understanding and can I explain it to someone else?

## Depth Level 1 — Conceptual
[ ] I can define the concept
[ ] I can explain it in my own words

## Depth Level 2 — Structural
[ ] I can draw a diagram
[ ] I can show how it works internally

## Depth Level 3 — Applied
[ ] I can write an example
[ ] I can debug a broken example
[ ] I can explain how it shows up in real systems

## Depth Level 4 — Integrative
[ ] I can connect it to other topics
[ ] I can explain how it affects performance, memory, or architecture

## Depth Level 5 — Reflective
[ ] I can explain how I use this in my own projects
[ ] I can identify mistakes I’ve made in the past related to this topic
